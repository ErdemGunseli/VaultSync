# Personal vault

A personal Obsidian vault. This is not the planning corpus - there is no floor schema, no
GTD structure, and no agent rules seeded here on purpose. Agents generally stay out of this
vault; it is yours to shape however you like.

It runs on the same sync infrastructure as the planning vault (VaultSync: a daemon mirrors
Obsidian Sync and this git repo in both directions), so notes here reach every device and
are backed by git history without you doing anything sync-related by hand.

## Layout

Deliberately sparse. `Notes/` is a starting folder - rename it, delete it, restructure
however suits you. Nothing here assumes a particular organizational scheme.
