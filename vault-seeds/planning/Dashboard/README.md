# Dashboard/

Empty on purpose. The control panel (Bases views, a Homepage landing note, a generated
`Next.md` snapshot) is built once a plugin stack is chosen for this vault - plugin choice is
deliberately not made by this seed. Until then, work directly in `../ideas/` and
`../inbox/`.

See the planning-corpus design doc (`planning/PLAN.md` section 4 in the QUANTSOC repo, or
wherever this vault's design notes end up) for the intended shape: Bases for
searchable/filterable views, a status-control layer for editing without leaving the note
list, and a landing note that links into both.
